# Photographer Websites

Two standalone Next.js photography portfolio sites.

## [photographer-portfolio/](./photographer-portfolio)

A cinematic, dark-luxury single/multi-page portfolio for a US/Europe-market
photographer. Next.js (App Router), TypeScript, Tailwind CSS, Anime.js,
GSAP ScrollTrigger, and a Three.js / React Three Fiber scroll-driven
"aperture" scene. Pages: Home, Gallery, About, Services, Contact.

```
cd photographer-portfolio
npm install
npm run dev
```

## [indian-wedding-photographer/](./indian-wedding-photographer)

A high-fashion editorial site (black / warm white / crimson, Bodoni Moda
display type) for the Indian wedding photography market. Covers the
multi-function wedding timeline (Haldi, Mehendi, Sangeet, Phere,
Reception). Pages: Home, Gallery, Weddings, About, Contact.

```
cd indian-wedding-photographer
npm install
npm run dev
```
